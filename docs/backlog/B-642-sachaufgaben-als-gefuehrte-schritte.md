# B-642 · Sachaufgaben als geführte Schritte

Abschnitt IV.5 („Probleme systematisch lösen“) lehrt ein Vier-Schritte-Vorgehen; eine Sachaufgabe ist mit einem
einzelnen Antwortfeld nicht sinnvoll abfragbar. Gedacht: eine Aufgabe als Folge geführter Schritte – Ansatz auswählen
(wie die Lösungsansatz-Karten L1–L6 auf S. 105), Ergebnis eintippen, dann die Rückschau „welche Lösung ergibt im
Sachzusammenhang Sinn?“ (die −77 Jahre im Picasso-Rätsel, die negative Kantenlänge). Die Lösungskärtchen-Aufgabe
(S. 123 Nr. 1) ist eine Sortieraufgabe. Baut auf B-640 auf.
