# B-524 · Vokabeltest im Format der Schule: englische Lückensätze, deutscher Wortkasten, frei geschrieben

Friedrichs Englischlehrer prüft Vokabeln in einem festen Format. Pugling soll Friedrich Tests **genau dieser Art**
regelmäßig stellen. So übt er die Prüfungsform, die in der Schule zählt, und nicht nur die Vokabeln.

Das Format, aus dem echten Test vom 11.11.2026:

- **Englische Lückensätze** (etwa 12 Stück, je eine oder zwei Lücken) aus dem Wortfeld einer Unit.
- **Wortkasten auf Deutsch**, ungeordnet, mit mehr Einträgen als Lücken. Er nennt die Bedeutung, nicht die
  Schreibweise. Ablenker sind Wortfamilien (Rassismus/rassistisch).
- Das englische Wort wird **frei geschrieben**, in der Form, die der Satz verlangt (Plural, Wortart, Wortpaar).
- **Rechtschreibung zählt halb:** Ist die Bedeutung richtig, das Wort aber falsch geschrieben, gibt es −½ Punkt.
  Ein falsches Wort kostet den ganzen Punkt.

Warum das wichtig ist: Im echten Test hatte Friedrich alle Bedeutungen richtig. Jeder Abzug kam von der
Rechtschreibung („clinik“, „heiht“, „femal“). Ein Lückentext mit **englischer** Wortbank zum Anklicken (vermutlich
der heutige Cloze-Weg, siehe B-461/B-487) übt genau diese Schwäche nicht. Ob Pugling den Wortkasten schon auf
Deutsch zeigen, freie Eingabe verlangen und halbe Punkte für Schreibfehler vergeben kann, ist noch nicht am Code
geprüft (`unverifiziert`).

Verwandt: B-419 (neue Wörter werden kalt getippt abgefragt), B-03/B-06 (Lückensätze), B-461, B-487.
