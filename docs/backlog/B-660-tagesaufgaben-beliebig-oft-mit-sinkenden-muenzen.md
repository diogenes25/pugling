# B-660 · Tagesaufgaben beliebig oft spielen, die Münzen sinken je Wiederholung bis 0

Friedrich möchte eine Tagesaufgabe nach dem Erledigen **noch einmal** machen, statt dass sie für den Tag
abgeschlossen ist. Der Vater ist einverstanden, solange sich das nicht ausnutzen lässt: jede Wiederholung
zahlt weniger Münzen als die vorige, bis sie am Ende **0** zahlt – üben darf er dann weiter, so oft er will.

Beim Ausformulieren gegen den Code zu klären: Wie sperrt die Startseite eine erledigte Pflicht heute, und
was zahlt eine zweite Runde jetzt schon (Grenze „schon heute gewertet" in `scored`, Degression des
Bonus-Trainings aus [B-538](B-538-bonus-muenzregeln-form-und-degression.md), Kür-Münzen aus
[B-657](B-657-kuer-uebungen-zahlen-muenzen.md))? Zu entscheiden: Form der Abnahme (Halbierung, feste
Stufen), gilt sie je Position oder je Tag, und zählt eine Wiederholung für den Leitner-Kasten.
