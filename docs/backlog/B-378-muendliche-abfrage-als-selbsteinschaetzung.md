# B-378 · Prüfauftrag: eine mündliche Abfrage als Selbsteinschätzung ohne KI-Bewertung?

Baobabs „InterroBao" stellt offene Fragen mündlich, und eine KI bewertet die gesprochene Antwort. Das
bricht bei uns zwei Entscheidungen: kein LLM im Backend, und der Server ist autoritativ. Zu prüfen ist
eine eingehegte Form: die App liest die Frage vor, das Kind antwortet laut, danach wird die erwartete
Antwort gezeigt und das Kind schätzt sich selbst ein (gewusst / halb / nicht) – wie bei einer
Karteikarte, deren Rückseite man umdreht. Zu klären: ob eine Selbsteinschätzung beim Leitner-Stand
zählen darf (Selbstbetrug) oder nur übt, und ob das ein eigener Übungstyp ist oder ein Modus bestehender
Typen. Hängt am Gerätevorbehalt [B-31](B-31-geraete-vorbehalt-klang.md) und berührt
[B-252](B-252-vorlesen-und-sprechen-bei-vokabeln.md) (Vorlesen). Eine belegte Antwort „nicht bauen"
ist ein zulässiges Ergebnis.
