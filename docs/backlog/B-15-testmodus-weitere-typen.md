# B-15 · Vorschau für die nicht-prüfbaren Übungstypen

Der Vater kann eine Übung vor dem Zuweisen durchspielen — aber nur, wo es eine Prüflogik gibt. Für
Reading, Essay, Listening, Grammar und Birkenbihl fehlt eine reine **Ansicht** (bewusster v1-Scope).

**Ungeprüft:** welche Typen heute genau am Vorschau-Endpunkt scheitern und ob eine „nur anzeigen"-Variante
ohne Bewertung ins bestehende Preview-Modell passt.
